# 🏠 오손도손
청년들의 경제적 문제해결을 위한 룸메이트 매칭 시스템

## 기획배경 및 설명

오손도손은 청년들의 가장 큰 경제적 부담인 주거비 문제와 더불어 사회적 고립 문제를 해결하기 위해 기획된 **성향 기반 룸메이트 매칭 플랫폼**입니다. 단순히 조건만 맞추는 기존 서비스와 달리, MBTI와 생활 성향 체크리스트를 활용해 잘 맞는 룸메이트를 찾아주는 데 중점을 두어 **관계 만족도와 공동생활의 안정성**을 함께 높이고자 했습니다.

- MBTI와 체크리스트 기반 정보로 **성향 기반 룸메이트 매칭률** 산출
- 희망 지역, 월세, 관리비, 주거 형태 모집글 입력 및 필터링 지원
- 공통 태그와 매칭 점수로 **매칭률 가시적 제공**

오손도손은 성향과 조건을 동시에 고려한 매칭을 통해, 단순 주거 공유를 넘어 청년들의 주거비 절감, 생활 안정, 사회적 연결망 확대에 기여하는 것을 목표로 했습니다.

- 진행 기간: 2025.09.
- 팀 구성 및 담당 역할: 총 6명(디자인 1, 프론트엔드2, 백엔드 3)

## 나의 역할 및 구현 내용

- 모집글 도메인 설계와 CRUD API 구현
- 지역, 가격, 주거 형태 기반 필터링
- 모집글 지원 및 수락,거절 요청 처리 로직
- 성향 매칭 점수 기반 정렬 기능 구현
- 응답 구조 통일

## 사용스킬
`Spring Boot`, `MySQL`, `AWS S3`
